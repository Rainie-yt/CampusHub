## 四、已知限制（不属于缺陷，答辩时可说明）

1. 积分按"已报名且活动已结束"计算，没有签到环节。
2. 已有人报名或候补的活动不允许修改时间，避免破坏已通过的冲突检测。
3. 候补中的用户也占用时间，因此不能同时候补两个时间重叠的活动。
4. 数据文件使用 `|` 分隔，输入内容里的 `|` 会被替换为空格。
