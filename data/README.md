# 数据文件说明


## users.txt

作用：
保存系统所有用户的基本信息。

用途：
1. 用户登录验证
2. 用户注册保存
3. 用户信息修改
4. 用户角色权限判断
5. 用户兴趣推荐


数据格式：

用户ID|用户名|密码|角色|专业|兴趣|状态


字段说明：

1. 用户ID
   - 用户唯一编号
   - 格式：U001、U002


2. 用户名
   - 用户显示名称


3. 密码
   - 用户登录验证信息


4. 角色
   - Student：普通学生
   - ClubManager：社团负责人权限
   - Admin：管理员


5. 专业
   - 学生个人信息


6. 兴趣
   - 用于社团推荐
   - 多个兴趣使用逗号分隔


7. 状态
   - normal:正常
   - frozen:已冻结，不能登录
   - 旧数据没有这一栏按normal处理


示例：

U001|张三|123456|Student|计算机科学|机器人,人工智能|normal
